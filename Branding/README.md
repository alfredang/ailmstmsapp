# TIA LMS icon

User-requested premium blue company branding with TIA LMS lettering. The original generated artwork is preserved in TIA-LMS-original.png. The app asset is opaque 1024x1024 PNG. The app display name remains Tertiary LMS.

Run swift scripts/make-icon.swift to normalize the source, then swift scripts/verify-icon.swift on the source and compiled device icons. Visually inspect Apple masked and unmasked APP_STORE assets and the Apps overview separately; success in one does not establish success in the other.

Final design replaces the book/cap with the company T logo sourced from https://www.tertiaryinfotech.com/ (image: https://pub-62aa61537a134e9780c302c6f0795233.r2.dev/uploads/tertiary-logo.png). Build 4 was uploaded but not submitted; build 5 carries this company-logo design.
